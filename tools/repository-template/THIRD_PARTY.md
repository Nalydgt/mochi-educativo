# Atribuciones y condiciones

Este conjunto contiene componentes con licencias distintas. No existe una
concesión MIT global para todo el monorepo.

| Componente | Condiciones conservadas |
| --- | --- |
| Coucou, código adaptado | `Coucou-MIT.txt` |
| Coucou/Mochi, nombre, personaje, expresiones, animaciones y otros assets | `Coucou-ASSETS.md`; separados del MIT del código |
| Muse/display | `Muse-Apache-2.0.txt` y avisos en el componente |
| Montserrat | `Montserrat-OFL.txt` |
| Microfrontend/TensorFlow/KissFFT/WireGuard y dependencias locales | Sus archivos `LICENSE`, `COPYING` y `UPSTREAM` junto al código |
| OneWorks, alternativa no seleccionada | `firmware/assets/mochi-original/OneWorks-MIT.txt` y `NOTICE.md` |
| Otros componentes o servicios históricos | Avisos existentes en sus carpetas y lockfiles |

Conserva los textos originales. El hecho de que un modelo, biblioteca o
herramienta tenga licencia abierta no otorga derechos sobre todas las marcas,
voces, pesos, imágenes o referencias que puedan utilizarse con ella.

La identidad seleccionada de Coucou se conserva para el uso personal y las
demostraciones indicadas por el propietario. Esta preparación de un repositorio
privado no afirma que exista permiso para publicar derivados, releases, arte o
una aplicación comercial. Antes de cambiar ese alcance, revisa las condiciones
del titular o usa una identidad con los permisos correspondientes.
