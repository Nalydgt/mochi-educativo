# Alcance de uso personal

La selección actual conserva el personaje y las animaciones de Coucou/Mochi
para uso personal y demostraciones, por decisión del propietario. Este archivo
registra ese alcance; no crea derechos nuevos ni modifica las licencias ajenas.

El repositorio se prepara como privado y sin GitHub Releases automáticas.
Conserva `licenses/Coucou-MIT.txt` y `licenses/Coucou-ASSETS.md`: el MIT del
código no cubre de forma general el personaje, las expresiones, las animaciones,
los sonidos ni las marcas. No declares todo el contenido bajo MIT.

No se exportan credenciales, PIN, conversaciones, bases, grabaciones ni pesos
privados. Los archivos de configuración reales siguen perteneciendo al entorno
del operador y deben mantenerse fuera de Git.
